(`cmd/sysmon` + `internal/activity/{domain,port,service,adapter}`), add a

macOS/cgo code behind an adapter, following the architecture spec in
docs/TASK.md §10, while preserving the exact current behavior (flags, 1px
nudge-and-back with ~40ms pause, real kCGEventMouseMoved event, 10s default,
clean SIGINT/SIGTERM exit 0, ticker sleep with no busy-wait).

Output: The four-package hexagon under internal/activity, a new
cmd/sysmon/main.go entry point, a committed generated Pointer mock, a passing
race-enabled unit test, an updated Makefile, and the removed root main.go.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI flags → process | `-interval` string parsed by `flag.Duration`; validated `> 0` by `domain.NewInterval` before a ticker is built. Single-user local CLI; no network, auth, or persistence boundary. |
| Go process → macOS (cgo/CoreGraphics) | `CGEventPost` posts a synthetic mouse event; gated by macOS TCC (Accessibility), an OS-level control, unchanged by this refactor. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-01 | Denial of Service | adapter/cgpointer.go (CGEventRef lifecycle) | medium | mitigate | Preserve BOTH `CFRelease(cur)` and `CFRelease(move)` verbatim (Task 5, grep count == 2) — a dropped release leaks CF objects over hours of runtime. |
| T-01-02 | Denial of Service | domain.NewInterval / service ticker | low | mitigate | `domain.NewInterval` rejects `d <= 0` (Task 1) before `time.NewTicker` (which panics on non-positive), preventing a crash/busy-loop. |
| T-01-03 | Tampering | go.mod test-only deps (testify, go.uber.org/mock) | low | accept | Both are widely-used, well-known Go modules; test-only (not linked into the binary). No package-legitimacy checkpoint required — see note below. |

Note: testify (`github.com/stretchr/testify`) and go.uber.org/mock are
established, high-reputation Go modules explicitly locked by the user's test
convention (CONTEXT.md). They are test-only requires, never linked into the
stdlib-only production binary. This phase introduces no untrusted/[ASSUMED]/[SUS]
packages, so no blocking package-legitimacy checkpoint applies (RESEARCH.md
Package Legitimacy Audit: not applicable / test-only known deps).
